# Archive: historical HDL snapshots

Not part of any build or source list. Kept so that every piece of RTL ever written for the project is preserved.

| Folder | What it is |
|---|---|
| `archive/_recovery_backup/` | Pre-recovery copies of the original NoC, crypto and TRNG sources (Sep/Oct 2026) |
| `archive/CODEX_HANDOFF/` | Planned-source snapshot from the 10 Nov 2026 handoff |
| `archive/logs/` | Router mutants (N-6 mutation campaign) and testbench snapshots from debugging runs |

The live sources are under `rtl/`, `NOC_PQATTEST.srcs/`, `sim/`, `sim_riscv/` and `synth/`. Per-run source snapshots under the raw evidence directories (`reports/dual_lane_10_*`) are copies of these sources at run time and are not included.
