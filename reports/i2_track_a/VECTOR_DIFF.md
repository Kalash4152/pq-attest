# I-2 Track A: vector diff after the V7 adapter rewrite

Date: 2026-10-19. Branch base: `noc/credit-integration` at `0b5c0d6`.
Scope: `vectors/*.json` and `vectors/*.svh` regenerated with `--write` by the rewritten
`scripts/s8_golden.py`, `scripts/full_chain_golden.py` and `scripts/l2_golden.py`, which are now
thin adapters over the pinned teammate reference (`Pq_Attest_final.zip`
`047bb5a981050f11a572a60e850f7c7511ff5d636f7903c6a8d239891003c6a0`, extracted at
`software/pq_attest_final/PQ_Attest/software/`).

## Conclusion

**No payload byte changed.** Every key, measurement, tag, 776-bit response, input field, the
36 directed L2 keys (9216 bits), all 18 L2 directed packets and the TX packet are byte-identical to
the committed vectors. The only differences are provenance metadata: three or four added or changed
JSON keys per `.json` file, and the first line (a `//` comment) of each `.svh` file. This matches V5
(the repo and ZIP KMAC outputs are identical) and confirms that the old reconstructed oracle and the
teammate API agree on the whole vector set.

Method: the committed files were copied before `--write`. The script then parsed both JSON
versions and compared every top-level key except the metadata set {`oracle`, `reference_zip`,
`reference_sha256`, `tile_key_bytes`}. It also compared both `.svh` versions line by line, byte for
byte. `git diff -U0 vectors` shows the same result: 12 insertions and 4 deletions, all of them listed
below.

## What changed in the oracle (no output effect)
- Repo `software/kmac128_ref.py` → teammate `kmac128_ref.kmac128` / `derive_tile_key(key_bytes=32)`.
  The repo copy is now a **supplementary KAT only**. It is no longer imported by any adapter, and it
  was not edited or deleted.
- `hashlib.sha3_256(tile+config+imem)` → teammate `measurement_ref.measure_tile`.
- Inline `kmac128(..., 32, b'PQ-ATTEST-AUTH')` → teammate `attestation_protocol.tile_respond`.
  The adapter also calls `verifier_check`, which must ACCEPT. Two RTL KMAC-core literal cases
  (`pqattest_tb` V07 with L=16 and V08 with an empty customization) are not protocol tags. They use
  the teammate `kmac128` primitive directly.
- Import guard: the teammate directory is placed first on `sys.path`. Every reference module's
  `__file__` must resolve inside `software/pq_attest_final/` and be a pinned member. All 15 member
  hashes are checked against `docs/decisions/dual_lane_config.json` `python_reference.members`
  before use. Bytecode writing is disabled, so no `__pycache__` appears under the immutable tree.

## Limitations carried
L-1: split ambiguity (K-3), mitigated only by provisioning in `policy_layer.py`. L-2: the reference
verifier is stateless. L-3: deterministic demo keys and nonces. L-4: 135-byte cap.
