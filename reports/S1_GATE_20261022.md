## Root causes found this session (details in reports/S1_NOTES_20261021.md sec. 5, 5a, 6)

- **M10 lines in the plain-tile NIs:** an XSim evaluation artifact, not a protocol violation.
  - Tautological concurrent properties failed only while the NI's ports were bound to packed-array elements under the nested generate.
  - Fix: scalar port wiring (pure wiring), plus clocked twins of AM-2 and the three RX checks. The twins never fired.
  - The originals are unchanged.
- **Chained `automatic` declarations with a cast initializer:** XSim 2024.1 leaves a later declarator X. Measured in a standalone test.
  - This broke tb_p7_ingress, and silently weakened tb_p7_c4 and tb_p7_refuse_grant. Both were rerun; the earlier runs are not relabelled.
  - Guard: preflight lint `lint_chained_cast_init`, with a negative test.
- **tb_sf1_flood:** the latency wait never ended when authorized never rose. It now uses a per-cycle counter, plus a 50 ms global TB_TIMEOUT.
- **p7_refuse_grant:** no longer uses force. A bench-only TB_INJECT parameter is 0 in synthesis and in every other job.
