## 4. What did not go to plan (all recorded, nothing relabelled)

1. **A5 was withdrawn on measured data** (contract sec. 6). In run `192324_9cde1d22`'s synthesis it removed 1,600 FF per
   engine but **added about +790 LUT per KMAC engine**: the zero / hold moved from free FF reset / enable pins into a
   1,600-bit select that cannot merge across the `-flatten_hierarchy none` boundary. The Step A estimate had the sign wrong.
   Its mutant `s3_mut_absorb_zero` was KILLED in run `190244_e66e835d`; that record is kept, and the job left the increment.
2. **`s3_mut_state_in` INVALID** in run `183915_69aa2d1b`, "unrelated failure G00_TAG". Cause: my frozen scope was the oracle
   only, but the tag is computed over the measurement, so TAG and FULL_RESPONSE must also fail. The record stands. A new job
   `s3_mut_state_in_r2` was frozen with kill_scope `G..(MEASUREMENT|TAG|FULL_RESPONSE)$` (contract sec. 5).
   **This scope was written after seeing the INVALID run**; it is justified by the causal argument, not by the observation,
   and it still rejects any other failing check.
3. **s3_p7_pnr INVALID** in run `192324_9cde1d22`, at the post-synthesis child-engine check: the expected hierarchy predated
   S3.
   - **Fix:** scripts/d4_crypto_ooc_child.tcl got structure-aware S3 rows when `endpoint/controller/u_perm` exists (the B-3
     precedent), still gating every real engine including `u_perm` and its round.
   - **Check:** verified on the S3 synth.dcp (53 rows, 0 fails) before the final run.
4. **Harness refused the first start** (run folder `183845_a5eea22b`, no job ran): I switched the increment after building
   the payload. The payload was rebuilt.
5. **A false commit message:** dede4d3 said "test_dual_lane.py 107/107 OK" while one test was failing
   (SelectionDependencyTests: `s3_p7_pnr` depended on `s3_variant` across selections, wrong since 3fd5411). Corrected in
   c85df47; self-tests now pass, checked by exit code.
6. **Lint waiver added:** scripts/rtl_lint_waivers.json pins `rtl/dual_lane/kmac_128_xp.sv:202`, the KMAC domain-byte write
   inherited verbatim from production kmac_128.sv:194-196 (present in all four registered engines, not introduced by S3).
   **Flagged for Kalash** because the original waivers were his B-1 approval.
