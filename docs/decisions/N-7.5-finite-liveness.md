# Channel and protocol dependency argument

XY dimension order eliminates cyclic route dependencies for the mesh channels.
FD-1 per-output wormhole locks persist until terminator. VC0/VC1 separate memory
request/response, but VC2 carries both attestation directions. The protocol
therefore enforces one RoT outstanding challenge mesh-wide. The RoT does not
issue another while busy; the endpoint drains extra incoming packets during
crypto/TX. Auth wrappers consume entire network packets before KMAC and drain
overload. No crypto engine retains a router lock while waiting for its result.

These conditions remove the intended endpoint wait cycle; finite saturated
VC2, reset/drain and second-challenge tests are still required. A deliberately
truncated sender can retain wormhole ownership: there is no router timeout and
no claim to cure that frozen behavior. Watchdogs and finite simulation are not
formal deadlock freedom. Production stall bounds and real Lane-2 consumption
contracts remain separate prerequisites. Three VCs remain unchanged.
